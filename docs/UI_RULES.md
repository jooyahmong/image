# UI Rules

## Product Identity

- Preserve the existing WOOJOO Image visual identity unless a redesign is explicitly requested.
- Keep the interface clean, simple, creator-focused, and beginner-friendly.
- Avoid overly technical language in user-facing copy.
- Keep English and Korean layouts structurally aligned.

## Extract Elements Flow

1. Upload
2. Review
3. Export

- Do not add a separate job-queue step for normal use.
- Put the working surface before marketing content.
- Show extracted elements visually as thumbnails or cards.
- Each element card supports a selection checkbox, preview, generated filename, rename/edit, and exclude/remove.

## Responsive Behavior

- Support desktop, tablet, and mobile.
- Avoid horizontal overflow and clipped controls.
- Keep primary controls touch-friendly and visible near the relevant content.
- Use readable type and preserve the established spacing, colors, cards, borders, and corner treatment.

## Donation

- Donation UI must be subtle.
- Do not show a blocking donation popup.
- Place a donation call to action near a successful export or in a small support area.
